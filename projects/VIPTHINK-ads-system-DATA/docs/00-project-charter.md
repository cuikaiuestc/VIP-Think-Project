# 00 项目宪章

## 项目名称

Meta 投放闭环系统

## 项目定位

本项目是一个独立的新项目，目标是让投放师在本地完成一条可用的 Meta 投放诊断与优化草稿闭环。

旧项目 `REDACTED_PROJECT投放全自动系统/intelligent-ad-system` 只能作为参考库。本项目不继承旧项目的多版本原型、平台导航壳、ABC 分工或历史文档结构。

## 目标用户

一线投放师、投放负责人，以及需要查看投放诊断证据和复盘结果的增长团队成员。

## 第一阶段目标

完成一条真实可用闭环：

1. 读取真实 Meta read-only 数据。
2. 展示账户、Campaign、Ad Set、Ad 的关键状态。
3. 识别需要处理的异常或机会。
4. 给出诊断证据。
5. 生成本地优化草稿。
6. 阻断所有真实写操作。
7. 输出本地报表和复盘。

## 非目标

- 不做真实广告写操作。
- 不做静态信息图交付。
- 不先堆完整平台导航。
- 不让用户从底层字段开始理解产品。
- 不机械复刻 XMP。
- 不把凭证、token 或真实账户敏感信息写入项目文档。

## 成功标准

- 投放师可以打开本地系统，看懂当前账户和 Campaign 的处理优先级。
- 每条诊断都有数据证据和可追溯来源。
- 本地优化草稿可以保存，但不会触发真实 Meta 写操作。
- 危险动作在代码层和测试层都能证明被 blocked。
- 当 Meta 权限或凭证不可用时，系统能退回 mock-to-live adapter 和权限缺口清单。

## 当前确认闸口

本次只完成干净初始化。下一步进入代码实现前，需要确认是否开始迁移最小 Meta read-only adapter 与测试。
