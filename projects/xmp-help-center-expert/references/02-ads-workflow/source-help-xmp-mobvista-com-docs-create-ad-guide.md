# 创建广告

This is a compact distilled note. Use the raw source for audit, exact wording, or re-distillation.

## Key Rules

- 借助 XMP 能够实现快速批量创建广告。例如，添加 2 个广告帐户、5 个定向以及 10 组创意，便可一次性生成 2×5×10 = 100 条广告。
- 本文将为您介绍如何通过 XMP 给主流媒体批量创建广告，如：Facebook、Google、TikTok 等。
- ## 二、操作步骤 ### 操作视频教程 **** ### 详细操作步骤 进入推广页面 ，在左侧渠道栏中选择投放渠道，点击页面右上方的 “创建广告”按钮。
- [image omitted from clean public release] 以Facebook 创建广告为例： ### Step 1 选择广告系列类型 创建广告系列是广告投放的第一步。您可以选择新建广告系列，也可以选择在已有广告系列的基础上添加广告组。选择新建广告系列时（①），可以选择历史的草稿或保存的模板，快速完成新建任务。
- > 批量叉乘和自由绑定是XMP 批量创建广告的两种组合方式，它们在自动化程度、灵活性和生成的广告数量方面存在差异，详细说明见高级功能介绍 ### ### Step 3 预览与发布 - 提交预览： 填写完所有必填信息后，点击“提交预览”，进入广告预览界面。
- [image omitted from clean public release] - 复制历史任务 - 在创建广告的初始化页面，点击“复制历史任务”，可以复用历史全部已发布过的草稿。
