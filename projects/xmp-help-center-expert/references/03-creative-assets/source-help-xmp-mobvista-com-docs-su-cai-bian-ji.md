# 素材编辑

This is a compact distilled note. Use the raw source for audit, exact wording, or re-distillation.

## Key Rules

- [image omitted from clean public release] - 目标文件夹：编辑后的素材保存在原素材文件的相同文件夹目录，或指定文件夹。
- 标签/设计师/创意人：原标签/原设计师/原创意人选项为不改变原有素材的标签信息，也可手动选择或者选择自动识别文件名的方式建立新的标签信息，非必填项。
- 素材名称：根据所选原文件名后增加 _尺寸_时长 后缀，如遇重名，使用原有_1后缀原则。如：原视频文件.mp4 → 原视频文件_1280x720_5s.mp4；
- 原图片文件.jpg →原图片文件_1280x720.jpg (图片素材无论是否选中时长后缀，均不出现该字段)。
- [image omitted from clean public release] 2.2 查看任务状态及素材文件 点击【详情】，查看该任务中各个素材的编辑内容及处理状态。
- [image omitted from clean public release] [image omitted from clean public release] ⚠️权限范围：上级用户可查看下级用户的任务，管理员可以查看全公司的任务。
- ⚠️通过素材编辑进入XMP素材库的素材，会标记Mindworks的角标，均禁止下载与导出，批量素材下载时候需跳过该类素材。
