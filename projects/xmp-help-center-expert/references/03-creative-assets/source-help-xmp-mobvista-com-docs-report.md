This is a compact distilled note. Use the raw source for audit, exact wording, or re-distillation.

## Key Rules

- ## 一、核心功能特点 > 💡可视化报表，聚合多维度数据 - 直观展示投放数据和回收数据，包括花费、展示、点击、转化、收入、留存等关键指标。
- [image omitted from clean public release] 在上图的弹窗中，设置看板的基础信息： - **看板名称：自定义名称，便于识别即可 - **看板位置：可以选择将看板放入哪个文件夹，进行分组管理 - **看板类型：选择综合报表、素材报表、产品报表或标签报表 > 🔔看板类型介绍 综合报表：支持跨渠道，跨账户的产品/商品、渠道、地区、账户、推广系列、广告组、版位等维度的报表。
- 素材报表：以素材或者标签，设计师等维度聚合的报表，可聚合同一个素材跨渠道跨账户数据，支持查看素材Roas等回收数据，全面评估素材获客成本和盈利能力。
- > 💡支持多种报表类型，自定义分组对比 - 支持综合报表、素材报表、产品报表、标签报表。
