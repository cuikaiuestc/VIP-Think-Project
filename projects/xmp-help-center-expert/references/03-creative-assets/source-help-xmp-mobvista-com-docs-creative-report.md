- title: "素材报表" source_url: "https://help-xmp.mobvista.com/docs/creative-report" authority_level: "official" confidentiality: "public" captured_at: "2026-05-12" --- # 素材报表 素材报表支持查看素材、素材组、设计师、标签、创意人维度的数据报表。
- ## 一、功能介绍 - 支持跨渠道汇总素材数据，即使素材同时投放在多个渠道、账号，XMP 素材报表支持查看该素材汇总的数据情况 通常情况下，优化师需要从各个广告平台导出数据报表，在 Excel 内还通过各种函数才能汇总整理出素材报表给到设计师。在 XMP 内，设计师可直接登录 XMP 查看跨渠道的素材报表，轻松定位优质和劣质素材。
- ## 二、操作说明 * 如需查看标签、设计师、素材组、创意人等报表，可在素材报表或XMP 素材库，添加标签、设计师、创意人、素材组等；
- [image omitted from clean public release] [image omitted from clean public release] **单渠道**素材报表还支持显示素材**生命周期**标签。
- 支持查看素材的 ROI、次留、LTV 等后端数据 - 支持查看程序化创意的素材详细数据，包括 Facebook AAA 广告、Google UAC 广告等 在 XMP 可直接查看，省去在广告后台查看程序化创意素材详细数据的繁琐步骤。
- 标签报表可用于精细化分析素材元素，例如将素材的风格、类型、元素、特点、人物打上标签，即可在标签报表内洞察优质的素材元素，进而优化素材迭代。
- 支持查看素材评分，素材效果一目了然 XMP 从多维度详解用户对素材的喜好，洞察广告创意与广告效果之间的关联，从而评估素材效果，提供素材评分辅助广告优化。
