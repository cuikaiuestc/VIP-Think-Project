# 一键上单

This is a compact distilled note. Use the raw source for audit, exact wording, or re-distillation.

## Key Rules

- 操作：投手使用“一键上单”功能，填入《宇宙冒险》的App Store链接，设置好统一的日预算和目标成本，并上传了5张游戏截图和宣传图。
- 渠道：同时勾选Google、Meta和TikTok三个渠道，并完成各渠道的账户、Pixel等必要设置。
- 结果：点击“提交任务”后，三个广告系列被自动创建。团队无需分别在Google Ads、Meta Ads Manager和TikTok Ads Manager中重复操作三次，实现了数小时之内全渠道广告的同步上线。
- ## 五、重要注意事项 - 前置授权：在使用前，请确保您的Google、Meta和TikTok广告账户已经在本平台成功授权 - 资产准备：请提前在各广告平台后台准备好对应的资产，如：Meta公共主页、Pixel；
- TikTok Pixel等，并确保它们已授权给所选广告账户 - 创意生成：上传高质量的“参考图片”至关重要，系统可能会基于这些图片为不同渠道的版位生成尺寸、格式合适的创意素材 - 渠道差异：尽管搭建流程统一，但各渠道的广告审核政策和时长不同，请密切关注各平台的审核状态
