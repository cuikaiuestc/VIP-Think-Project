# 2024功能更新公告

This is a compact distilled note. Use the raw source for audit, exact wording, or re-distillation.

## Key Rules

- 各渠道层级的创建时间、上次更新时间支持升降序 ## 2024年1月 ### Open API新增功能 1.
- 改动现有接口 — 广告报表和素材报表：新增v2版本，支持返回三方指标 — 获取素材详情：新增v2版本，变更部分字段名 — 上传素材：tag_name 字段定于2024年4月30日下线，客户需通过 tag_id 上报标签 注意：2024年4月30日将下线3个接口 — ① 广告报表v1接口 ② 素材报表v1接口 ③ 素材库获取素材详情v1接口 ### 标签版本上新 1.
- ## 2024年3月 ### 「投放诊断」功能上新 1.数据自动整合，一键掌握诊断结果 —直接展示投放产品的展现量、点击率等指标数据趋势，及时发现异常情况并采取相应的优化操作，确保广告稳定投放。
- 2.创建规则可选择系统模板、自定义模板 ### 看板功能优化 1.新增产品看板 —在“我的看板”处新增“产品看板”，可筛选特定产品或指定产品类型以查看和分析投放产品的对应指标数据。
- 2.低门槛上手，快速调整投放决策 —选择“添加产品”即可快速搜索或直接选择展示的产品并设置产品可见范围。
- ### 素材拒审优化 1.支持查阅素材的拒审次数和具体原因 2.支持通过拒审信息筛选素材 —可在“拒审信息”设置FB、GG、TT、Mintegral四个渠道的拒审情况以筛选素材。
- ### ### Facebook功能上新 1.创建支持使用已有帖子，可批量添加 2.创建支持表单广告，可按素材分配和批量设置 ## 2024年2月 ### Google渠道功能上新 1.支持批量复制广告系列 2.支持批量复制广告组到指定广告系列 3.支持批量复制广告到指定广告组 ### 看板功能上新 1.新增导航栏，通过文件夹管理看板 —新增左侧导航栏，支持通过文件夹进行看板管理 2.支持看板分享 —通过右上角的分享按钮分享看板，支持批量添加人员 —在导航栏“分享给我的”文件夹查看被分享的看板...
