# XMP 创建广告场景

## Key Rules

- 用户问“怎么创建广告”时，优先检索 `创建广告` 子页面，而不是只用首页入口。
- 如果用户问自动化创建，补充检索 `自动创建广告`。
- 如果用户问真实投放不成功、审核、消耗、权限或账号状态，公共帮助中心不足以确认原因，应转为 `blocked`。

## Use Cases

- XMP 怎么创建广告。
- 创建广告文档入口在哪里。
- 自动创建广告和普通创建广告有什么相关文档。

## Limitations

- 不判断用户账号是否具备创建权限。
- 不判断广告是否会投放、通过审核或产生消耗。
