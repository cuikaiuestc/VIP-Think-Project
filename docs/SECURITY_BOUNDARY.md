# Security Boundary

This is a strong-sanitized internal collaboration package.

## Allowed

- Mock/sample data.
- Field schemas.
- Local sample registry.
- Local report generation.
- Manual / partial / blocked module labels.
- Documentation describing expected upstream contracts.

## Not Allowed

- Real raw snapshots.
- Real normalized facts.
- Real account, learner, user, order, phone, IP, or person data.
- Meta, SmartBI, or Feishu credential material.
- SmartBI DATA CLI implementation.
- FB ad QA assistant brain.
- Diagnosis strategy, route contract, or automated decision logic.
- External write-back.
- Public release without explicit owner confirmation.

## Current GitHub Target

The proposed target is `https://github.com/cuikaiuestc/VIP-Think-Project`.

This target was observed as publicly visible during packaging. Push is therefore blocked until owner confirmation.
