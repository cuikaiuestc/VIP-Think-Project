## Publishing Boundary

This is the public work repository for company-related outputs. Before adding new work, confirm whether the artifact belongs here or in a private repository.

- Company work path: publish here by default when the content is intended to be public and shareable.
- Personal or uncertain path: keep private by default until the publication boundary is confirmed.
- Do not add private credentials, account exports, internal-only screenshots, private customer data, or unreviewed tokens.
- Do not add raw web captures, raw source mirrors, generated archives, private reports, or unreviewed screenshots.
- If a project needs examples, use fake data, public data, or clearly de-identified samples.

## Excluded From Public Release

The clean public version excludes these categories by default:

- `raw-captures/`
- `raw-sources/`
- `dist/*.zip`
- generated HTML reports
- image captures and screenshots that have not been reviewed
- private runtime files, logs, account exports, credentials, and tokens

See `PUBLICATION_RULES.md`, `PUBLISH_CHECKLIST.md`, and `COMPLIANCE_AUDIT.md` before adding new material.
